# "Try it yourself" Age Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public page at `/try/` on dev where anyone becomes a test citizen, receives an age credential in Paradym (store) or Inji Wallet, and uses it at two age-restricted demo sites, with an anonymous "recent checks" table.

**Architecture:** age-issuer gains a public, rate-limited `POST /try/citizens` that writes a `TRY-` citizen to the registry and returns an offer QR through the existing `issueOffer` path; a cleanup loop deletes `TRY-` citizens after 24 h. The verifier gains an optional `site` on age sessions and an in-memory `GET /recent`. Three static pages (`/try/`, `/try/social/`, `/try/shop/`) live in `services/verifier-web/try/` and talk only to `/api/try/` and `/api/verifier/`.

**Tech Stack:** Node 22 ESM, zero-dependency services (`node:http`), `node --test`, static ES modules (no build), nginx.

**Spec:** `docs/superpowers/specs/2026-11-27-age-try-it-design.md`

## Global Constraints

- Wallets on `/try/`: `paradym` → `vc+sd-jwt`, `inji` → `ldp_vc`. No Brazil SDK app option.
- Test citizen IDs start with `TRY-`. Deleted 24 h after creation. Credential `expirationDate` = earlier of `ageClaimsValidUntil(dob)` and creation + **7 days**.
- Name: 1–60 characters, letters (any script), spaces and `.'-` only. DOB: strict ISO date, 1900-01-01 ≤ dob ≤ today (UTC).
- Rate limit: 5 per minute per visitor IP, burst 5, on `POST /api/try/citizens` only. Cap: **1,000** live `TRY-` citizens → `503 {error:'demo_busy'}`.
- Recent checks: in memory only, last **50** within **24 h**, fields `{at, site, threshold, wallet, outcome, checksPassed, checksTotal, reason}`; never citizen ID, name, DOB, IP or transaction ID. `site ∈ {verifier, social, shop}`, default `verifier`. `wallet` = family: `dcql` → `openid`, `pex` → `inji`.
- Every new user-facing string in **EN, FR, PT, ES** in `services/verifier-web/i18n.js`.
- Page copy must say: "Demo data only — do not enter your real name or date of birth." and "In a real deployment this record comes from the national registry."
- `/verifier/` and all existing tests keep working unchanged. No core (`age_verifier`) changes. No changes to demo-oid4vc's nginx.
- Any live call against dev (registry writes, scripted wallet) needs Kartheek's go-ahead first (standing rule). Commits: no Claude co-author line.

## Review Focus

1. Impossible or edge dates ("2010-02-30", a future date, 29 Feb, today) → 400 with a clear field error, never a 500 or a credential. → Task 1 tests.
2. A name containing markup (`<img src=x onerror=…>`) → 400 at the API, and every page renders visitor-supplied text with `textContent`, never `innerHTML`. → Task 1 test + Task 5 check.
3. nginx's own `429` (HTML body) or `503 demo_busy` → the page shows "Too many requests, wait a minute" / "The demo is busy", not a generic error or a JSON crash. → Task 5 test on `tryErrorKey`.
4. The holder declines at a site → "You declined: nothing was shared", not "refused"; and it is recorded as `declined`, not `denied`. → Task 3 + Task 5 tests.
5. A poll after the verifier restarted (session 404) → the site shows "This check expired, start again", and `/recent` simply lacks it. → Task 5 test on `siteOutcome`.
